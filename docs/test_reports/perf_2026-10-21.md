# Jetson performance, TensorRT, memory and endurance — 2026-10-21

Jetson Orin Nano 8 GB, JetPack 6.2.1, TensorRT 10.3, torch 2.8, nvpmodel **MAXN_SUPER** (ID 2).
The GPU was shared with other benchmark jobs (each run held the GPU lock; their CPU load and the
navera-field service's Insta360 decoding ran beside): absolute times vary by ~±15 % between runs
of the same configuration (day 400 m baseline measured twice: 1361 and 1120 ms median).

Tools: `navera_tools/bench/perf_profile.py` (day / night / celestial / endurance, stages with GPU
synchronisation, peak RSS, torch memory, tegrastats + sysfs power, clocks, fan, over-current
counters), `navera_tools/bench/perf_gate.py` (frame-for-frame gate: identical acceptance,
positions within 1 m median, 0 new wrong fix > 50 m), `navera_tools/trt/build_engines.py`.

Inputs: day — the real-camera screen recordings `~/navera-field/day_image_2026-10-20/before/rec_*`
(10 runs, prior = truth + 0-150 m, the recorded scale and rotation; every 4th frame = 315 frames,
every 8th = 159); night — `night_conditions.py` synthetic frames (78 conditions x 8, the node's
heading / height retries); celestial — `celestial360_conditions.py` synthetic skies (54 x 1).

## Celestial (all-sky solver)

CPU only (numpy, no network): solve median 1.8 s, p90 4.7 s per frame (54 synthetic skies, one
process), peak RSS 832 MB including the renderer; the time is in `unproject` / `fit` /
`rays_for` / `detect_spots`. Nothing for TensorRT.

## Endurance: day pipeline 30 min at maximum rate (GPU lock held 15:11-15:41)

1530 frames (400 m search, recordings replayed back to back, no pause), MAXN_SUPER, stock fan
control. VDD_IN 16.9 W mean / 19.3 W max (CPU+GPU rail 8.6 / 10.5 W). tj rose to 71 C within 5 min
and stayed at **72.3 C max**; fan 3400 rpm (PWM ~140/255, not at maximum). GPU at 1020 MHz (its
MAXN_SUPER maximum) whenever busy, CPU up to 1728 MHz; latency first quarter 1114 ms, last quarter
1089 ms: **no thermal throttling**. Margin to the 99 C software throttle trip: 26.7 C at this
room's ambient (not measured; ~25 C assumed). Peak RSS 3257 MB, accuracy steady (1410/1470 located).

The soctherm over-current counter `oc3_event_cnt` rises ~30/s under this load (~6/s idle) with
no visible clock or latency effect; to be checked against the power supply and the 25 W budget.

At 50 C ambient the same ~47 C rise puts tj at ~97 C: about 2 C from throttling, before any
enclosure. The box needs either forced airflow through the heatsink (fan at full PWM, ducted
inlet/outlet) and a thermal-chamber check at 50 C, or the 25 W / 15 W nvpmodel (lower power,
slower: to be measured) — `sudo nvpmodel -m 1` (25W) / `-m 0` (15W), current `-m 2` MAXN_SUPER.
