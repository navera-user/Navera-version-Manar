MISSION BRIEF — ground engineer, NAVERA training flights
========================================================

The NAVERA box came back from two training flights (Sousse and the desert range).
All their files were copied, in a mess, into the folder "inbox".

  1. Build the mission folder:  mission/photos  mission/logs  mission/docs  mission/bin
  2. Sort the inbox: photos, logs, the pilot's notes (renamed notes.txt),
     the pre-flight script (in mission/bin, made executable); delete the .tmp files
  3. Copy NAVERA's GPS settings file into mission/docs, for the record
  4. Record the ROS environment of the box in ros_env.txt
  5. Start fake_node.sh in the background and stop it with a signal, by its PID
  6. Write mission/bin/log_report.sh: one summary for any NAVERA log
  7. Use it on both flights, explore ~/navera, fill in answers.py
  8. Write mission/docs/flight_report.md for the test team

Every step is done in the terminal. No mouse needed.
This brief is exactly 20 lines long (check it with: wc -l mission_brief.txt).

Good luck, engineer.
