Accounts and sign-in

    
Students can create their own account on the first page (e-mail), or sign in with Google / GitHub once those are set up.
      Their progress, XP, badges and intro/tour status are saved in their account.

    
    

    
How to switch on Google and GitHub sign-in
      
    
        
  1. Give the academy a public address with HTTPS (for example https://academy.your-company.com) — Google and GitHub refuse private addresses like 192.168.x.x.
    2. 
        
  2. Google: in Google Cloud Console → APIs & Services → Credentials, create an "OAuth client ID" (Web application) with the redirect URI https://YOUR-ADDRESS/auth/google/callback.
    3. 
        
  3. GitHub: in GitHub → Settings → Developer settings → OAuth Apps → New OAuth App, with the callback URL https://YOUR-ADDRESS/auth/github/callback.
    4. 
        
  4. Put the address and the keys in ~/navera-academy/state/oauth.json:
    
          {"base_url": "https://YOUR-ADDRESS", "google": {"client_id": "…", "client_secret": "…"}, "github": {"client_id": "…", "client_secret": "…"}}
          — the buttons switch on immediately.
    5.
