What this adds
• Roles: Admin (the client: organisation, logo, teachers, the Jetson's settings) → Teachers (their own classes only) → Students (their own work only). IRIS keeps a support account.
• Create account asks one question first — student or teacher. Students join with a class code / QR (their class is shown before they confirm), give the name printed on the certificate, and an optional student ID. Teachers need an invitation code from the admin, or wait for approval — so nobody makes themself a teacher.
• Classes: one button to create; a code + QR poster to print; options per class (who can join, which legs are open and when, seats, ranking, certificate wording). The teacher page shows one class at a time, with export to Excel.
• Certificates can print the class, the school and its logo next to IRIS.
