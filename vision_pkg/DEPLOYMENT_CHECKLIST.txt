TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: GPU not detected
SOLUTION:
  ☐ Run: python3 -c "import torch; print(torch.cuda.is_available())"
  ☐ Run: nvidia-smi (should show GPU)
  ☐ Check CUDA installation
  ☐ Restart Python interpreter

PROBLEM: Memory errors
SOLUTION:
  ☐ Reduce BATCH_SIZE from 32 to 16 or 8
  ☐ Reduce memory_fraction from 0.8 to 0.6
  ☐ Monitor with: nvidia-smi --query-gpu=memory.used

PROBLEM: Timeout errors
SOLUTION:
  ☐ Increase MATCH_TIMEOUT_SEC from 5.0 to 10.0
  ☐ Check GPU load: nvidia-smi
  ☐ Reduce batch size to free GPU memory
  ☐ Restart server to clear GPU cache

PROBLEM: DINOv2 fails to load
SOLUTION:
  ☐ Check internet connection (downloads model)
  ☐ Try NetVLAD: POST /api/gpu_config with {"model": "netvlad"}
  ☐ Check disk space (1-2GB needed for model)
  ☐ Reinstall PyTorch
