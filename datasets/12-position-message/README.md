# Mission 12 data

- `day_vision_lag.csv` — a synthetic bench log of a day-vision matcher, one row per photo:
  `frame,exposure_s,published_s,match_err_m` (when the photo was taken, when its position was published,
  both in seconds on the bench clock, and how far the match is from where the camera was when the photo
  was taken, in metres). Made for the course; it is not a recording.
