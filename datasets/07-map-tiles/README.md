# 07-map-tiles

`sousse_small.mbtiles` — 88 tiles copied from the course map of Sousse (MBTiles: SQLite, JPEG tiles, TMS rows):
around the Ribat of Sousse (zooms 13–19) and Port El Kantaoui marina (zoom 17).

Map data © OpenStreetMap contributors (https://www.openstreetmap.org/copyright), ODbL. The tiles are drawn from
OpenStreetMap data for NAVERA Academy; show the attribution wherever a picture made from them is shown.
