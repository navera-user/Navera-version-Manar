# Mission 16 data

- `attitude_log.csv` — `t_s, qx, qy, qz, qw`: the orientation of a simulated 150 s drone flight, 10 samples per second, as a `sensor_msgs/Imu` message stores it (ENU world, FLU body).
- `colleague_attitude.csv` — `t_s, roll_deg, pitch_up_deg, heading_deg`: the table a colleague's script printed from the same log.

Simulated data, written for the course.
